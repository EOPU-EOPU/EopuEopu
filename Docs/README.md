# 문서 안내

**전부 읽지 않는다.** 어느 쪽이든 **3개만** 열면 일할 수 있게 만들어 뒀다.

```
팀원 (네트워크 지식 0)   이 문서 → LEARN/01_CONCEPTS.md → 내 폴더의 CLAUDE.md
네트워크 담당 (매일)      STATUS.md → ROADMAP.md 현재 페이즈 → MOTION.md 해당 절
```

---

## 처음 합류했다면

```
1일차   이 문서 (5분)
        LEARN/01_CONCEPTS.md (30분)   ← 권위·예측·보간이 뭔지. 지식 0 대상
        SPEC.md 1~2절 (10분)          ← 무슨 게임인지

2일차   내 폴더의 CLAUDE.md (아래 표)  ← 여기서 뭘 하면 안 되는지
        API.md 의 내 베이스 절         ← 복붙 예제 있음
        ROADMAP.md 에서 내가 붙는 페이즈

막히면  LEARN/02_KINEMATIC.md · SPEC.md · 네트워크 담당에게 질문
```

### 내 폴더와 내 베이스

| 담당 | 전용 문서 | 폴더 규칙서 | 붙는 페이즈 |
|---|---|---|---|
| **플레이어 (HFSM · 입력 · 카메라)** | **[`PLAYER.md`](PLAYER.md)** ★ | [`_Game/`](../Assets/01_Scripts/_Game/CLAUDE.md) · [`_Local/`](../Assets/01_Scripts/_Local/CLAUDE.md) | P02~ |
| **AI (포식자·피식자)** | [API 2절 `NetServerAI`](API.md) | [`_Game/CLAUDE.md`](../Assets/01_Scripts/_Game/CLAUDE.md) | P06 |
| **맵 · 정화 퀘스트** | [API 1절 `NetObjective`](API.md) | 〃 | P07 |
| **능력 4종** | [API 3절 `NetAbility`](API.md) | 〃 | P08 |
| **UI · HUD · 연출** | [API 7절 UI 계약](API.md) | [`_Local/CLAUDE.md`](../Assets/01_Scripts/_Local/CLAUDE.md) | P07 |
| **네트워크** | [`MOTION.md`](MOTION.md) | [`_Net/CLAUDE.md`](../Assets/01_Scripts/_Net/CLAUDE.md) | P00~ |

> **플레이어 담당은 베이스를 상속하는 게 아니라 HFSM을 짜서 넘기는 구조**라
> 별도 문서가 있다. [`PLAYER.md`](PLAYER.md)를 먼저 읽는다.
>
> **AI 담당이 행동 트리를 쓴다면** `PLAYER.md` 1·6절(서버에서 tick · 시간은 틱으로)이
> 그대로 적용된다. 같은 구조다.

**`MOTION.md`는 네트워크 담당 전용이다.** 나머지는 안 읽어도 된다.

> **입력·카메라 담당은 P02를 기다린다.** 입력 프레임 계약이 나와야 거기 맞춰 붙일 수 있다.
> 그 전에는 로컬 목업으로 감각만 잡고, **목업을 그대로 인계하지 않는다.**

## 문서를 고칠 때

**규범은 한 곳에만 쓴다.** 이게 이 문서 세트의 유일한 설계 원칙이다.

| 바뀌는 것 | 고칠 곳 |
|---|---|
| 기능 범위 · 권위 | `SPEC.md` → 그 다음 `ROADMAP.md` 페이즈 조정 |
| 이동 계약 · 수치 | `MOTION.md` |
| 베이스 시그니처 | `API.md` + 실제 구현을 **같은 커밋에서** |
| 진행 상태 · 측정값 | `STATUS.md` |
| 뺀 기능의 설계 | 지우지 말고 `BACKLOG.md`로 옮긴다 |

**다른 문서에서는 복사하지 말고 링크한다.**
복사하면 결정이 바뀔 때 반드시 하나를 빠뜨리고, 그때부터 문서끼리 다른 말을 한다.

## 이 문서들의 신뢰 수준

- **구현 완료·컴파일 성공·플레이 검증을 의미하지 않는다.** 설계 계약이다
- `API.md`·`MOTION.md`의 선언을 그대로 `.cs`에 붙여 넣으면 컴파일되지 않을 수 있다
- 임계값·전송 주기·보간 지연은 **측정 전 시작값**이다.
  **계약 자체는 조정 대상이 아니다**
- 현재 **Mirror는 아직 설치되지 않았고 `.cs` 파일이 0개다.**
  계약 변경 비용이 가장 낮은 시점이다
