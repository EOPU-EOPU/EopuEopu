# EOPU EOPU — 물고기 협동 멀티

한국 토종 물고기 4마리가 오염된 강을 정화하는 **4인 협동 게임**.

```
Unity 6000.0.83f1 / URP / Mirror · 호스트 모드 · 6주 개발
팀 4명 전원 클라이언트 프로그래머 (네트워크 1 + 게임 기능 3)
```

---

## 어디서 시작하나

### ▶ **팀원이라면 [Docs/README.md](Docs/README.md) 부터**

거기에 담당별 읽는 순서가 있습니다. **네트워크 지식이 없어도 됩니다.**
첫날 읽을 문서는 **3개**, 45분이면 됩니다.

### ▶ 네트워크 담당이라면 [STATUS.md](STATUS.md)

현재 페이즈와 다음 작업이 적혀 있습니다.

---

## 게임

```
피식자를 먹는다 → 허기 회복 + 성장 → 능력이 세진다
                                        ↓
                          정화가 빨라진다 → 오염도 0% → 승리

그 사이 포식자를 피한다. 플레이어는 공격 수단이 없고 회피만 한다.
맞으면 HP가 깎이고, 0이 되면 15초 뒤 자동 부활한다.
허기가 0이 되면 HP가 계속 깎인다.
```

상류 · 중류 · 하류 3구역을 지나며 구역별 정화 퀘스트를 수행합니다.

> 기획서 PDF를 읽고 **"낚시바늘 어디 갔죠?"** 싶으면
> [Docs/SPEC.md](Docs/SPEC.md) 7절에 기획서 대조표가 있습니다.

## 실행

```
로컬    Host 먼저 실행 → 127.0.0.1로 Client 접속
원격    Tailscale 연결 후 호스트의 Tailscale IP로 접속
```

접속은 **호스트가 방을 열고 참가자가 IP를 직접 입력**하는 방식만 지원합니다.

상세 절차와 실행 스크립트(`Host.bat` / `Client.bat`)는 [Docs/TESTING.md](Docs/TESTING.md).

## 알려진 제한

```
4인 고정 (5번째는 거부)
호스트가 나가면 세션 종료 — 마이그레이션 없음
재접속 복구 없음
실패 조건 없음 — 게임은 승리로만 끝난다
```
